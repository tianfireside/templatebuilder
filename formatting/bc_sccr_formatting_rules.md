# BC SCCR Formatting Rules

## Scope
All rules apply only to content **before** the `Appendix` section. Everything from `Appendix` onward is left unchanged.

---

## Alignment

| Element | Rule |
|---|---|
| Form header line (matches `Form N...`) | Centered |
| All-caps form title | Centered |
| Rule notice line (matches `[Rule N-N ...]`) | Centered |
| `File Number:{{file_number}}` | Right-aligned |
| `Registry:{{registry_location}}` | Right-aligned |

---

## Bold

| Element | Rule |
|---|---|
| Section and division headings | Bold |
| All-caps form title | Bold |
| Address/fax/email label only — the label text up to and including `:` | Bold |
| `Filed by:` line | Not bold |
| All placeholder values `{{...}}` | Not bold |

---

## Numbered Lists

All numbered body paragraphs use Word's built-in numbered list (`List Number` style). Numbers are generated by Word, not typed manually.

- Content paragraphs (those with actual text after the number) → apply `List Number` style, strip the manually typed leading number
- Blank numbered placeholder paragraphs (just `1`, `2`, etc.) → apply `List Number` style, clear the text

### Dot-fill blanks within list items
Any dot-fill pattern inside a list item → replace with underscores: `________________`

## Signature Table

| Row | Cell 1 | Cell 2 |
|---|---|---|
| Row 1 | `Date: _________________` | `________________________` |
| Row 2 | *(empty)* | `Signature of {{lawyer_name}} [role]` |

- `[role]` is whatever follows the checkbox pattern in the original (e.g. `lawyer for defendant(s)`)
- The `[type or print name]` row is removed entirely
- Dot-only cells become `________________________`

---

## Style of Proceeding Block

Replace the single `[Style of Proceeding]` placeholder with:

```
File Number:{{file_number}}       ← right-aligned
Registry:{{registry_location}}    ← right-aligned
{{Style_of_Cause}}                ← default alignment
```

---

## Placeholder Rules

| Pattern | Replacement |
|---|---|
| `.................[party(ies)].................` | `{{client_name}}` |
| Bracketed instruction after a label (e.g. `Label: [Set out...]`) | `Label: {{inferred_name}}` |
| Bare label ending in `:` with no value | append `{{inferred_name}}` |
| `[  ] option1 [  ] option2` checkbox pattern | `{{lawyer_name}} option2` |
| Any `.......[description].......` dot-fill | `{{inferred_snake_case_name}}` |

Placeholder names are inferred from the surrounding label or bracket description text using snake_case. The filing party is always `{{client_name}}`.
